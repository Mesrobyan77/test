# test-posgres

## Description
This is a simple Express.js project that includes middleware for handling requests, sessions, and cross-origin resource sharing (CORS). The project also supports automatic server restarts using Nodemon.

## Technologies Used
- Node.js
- Express.js
- PostgreSQL (assumed based on the project name)
- Body-Parser
- CORS
- Express-Session
- Nodemon

## Installation
1. Clone the repository:
   ```sh
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```sh
   cd test-posgres
   ```
3. Install dependencies:
   ```sh
   npm install
   ```

## Usage
1. Start the server:
   ```sh
   npm start
   ```
2. Start the server in development mode with automatic restarts:
   ```sh
   npm run dev
   ```

## Scripts
- `npm start` - Runs the server using Node.js.
- `npm run dev` - Runs the server with Nodemon for development.
